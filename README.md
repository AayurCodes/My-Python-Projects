# 🛒 Smart Shopping Cart Tool
A Python-based CLI application designed to help users manage a list of goods with built-in logic for repeat items.

### ✨ Features:
- **Case-Insensitive Input:** Automatically handles "Apple" vs "apple".
- **Duplicate Detection:** Alerts the user if an item is already in the cart and asks for confirmation to add another.
- **Easy Exit:** Uses a simple "2" command to stop and display the final summary.

### 🚀 How to Run:
1. Ensure you have Python installed.
2. Run `python shopping_cart.py` in your terminal.
3. Follow the prompts to add your items!
 

 # 🏆 Kaun Banega Crorepati (KBC) CLI Game
An interactive quiz game that mimics the popular TV show format, testing logic and user input handling.

### ✨ Features:
- **Input Sanitization:** Uses `.strip().title()` to ensure user answers match correctly even with extra spaces.
- **Tiered Rewards:** Tracks winning amounts across multiple levels.
- **Game Logic:** Immediately ends the session and displays the correct answer upon an incorrect guess.

### 🚀 How to Run:
1. Run `python kbc.py` in your terminal.
2. Answer the questions to win virtual rewards!
